# AIR Artifact Templates

Status: active templates

These templates support AIR release/review governance:

- `PRESSURE_REQUEST.md`
- `ARCHITECTURE_DECISION.md`
- `CHANGESET_SUMMARY.md`
- `QA_REPORT.md`
- `RELEASE_DECISION.md`
- `BUNDLE_MANIFEST.json`

Use the smallest complete set needed for the change under review. Templates are
review artifacts, not npm package contents.
