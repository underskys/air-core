# AIR v0.27 RFC: Host ABI 0.11 Stabilization

Status: planning

Target milestone: v0.27

v0.27 stabilizes the Host ABI `0.11` bounded `output.emit` first slice accepted
in v0.26. It does not add new Host ABI imports and does not expand
`output.emit`.

The only accepted Host ABI `0.11` runtime import remains:

```text
output.emit(output_id:i32, arg0:i32, arg1:i32, arg2:i32, arg3:i32) -> i32
```

## 1. Non-Goals

v0.27 does not implement:

- `output.event`;
- `audio.event`;
- `effect.event`;
- dynamic `output_id`;
- strings, objects, maps, slices, pointers, binary payloads, or runtime JSON;
- raw Chrome, DOM, DB, cloud, Kubernetes, Jira, fetch, filesystem, or secret
  authority;
- host object handles;
- automatic host-side action guarantees;
- generated emit wrapper functions;
- production platform adapters.

## 2. Stability Matrix

The Host ABI `0.11` first slice is stable only if every layer agrees:

| Layer | Required behavior |
| --- | --- |
| Package manifest | Packages that use `output.emit` declare Host ABI `0.11`; Host ABI `0.10` packages remain valid when they do not use the import. |
| Output Contracts | Static output ids resolve to package-local Output Contract entries with first-slice scalar `i32` args. |
| Verifier/package-check | Dynamic ids, invalid ids, missing capability, missing effect budget, non-i32 args, and unsupported profiles fail deterministically. |
| Wasm lowering | The `output.emit` import appears only when declared/used; packages without it do not gain the import. |
| SDK imports | SDK helper imports stay scalar-only and do not add payload helpers or side-effect guarantees. |
| Host profiles | Profiles expose required/supported Host ABI and `output.emit` support explicitly. |
| Mock host | Policy decisions and status codes are deterministic and side-effect-free. |
| Verification evidence | Evidence reports emit usage, output ids, contract mapping, profile compatibility, and decisions without raw payloads. |
| LSP | LSP-lite and diagnostics-only Full LSP expose stable `air.output_emit.*` diagnostics. |
| API gates | Gates reject all deferred event/output surfaces and raw authority. |

## 3. Adapter Evidence

v0.27 adapter evidence is not production host implementation.

Acceptable evidence:

- mock-host evidence for accepted, denied, unsupported, invalid id, and budget
  cases;
- reference adapter documentation showing how a host maps scalar emit records to
  a policy layer;
- deterministic replay fixtures;
- report/evidence snapshots with no timestamps or absolute paths.

Rejected evidence:

- real cloud, filesystem, browser, database, Kubernetes, or network authority;
- tokens, credentials, raw URLs, raw logs, or private text;
- host object handles;
- side-effect success claims without host policy evidence;
- demo-specific behavior presented as public Host ABI semantics.

## 4. Profile Compatibility

Reports and verification evidence must show:

- package required Host ABI;
- selected profile Host ABI;
- required/supported/unsupported host imports;
- required/supported/unsupported capabilities;
- deterministic diagnostics for unsupported profiles.

For `output.emit` packages, `profileCompatibility.requiredHostAbi` should be
`0.11`, and `profileCompatibility.supportedHostAbi` should reflect the selected
profile.

## 5. Mock Host Consistency

The reference mock host should preserve v0.26 status semantics:

| Status | Meaning |
| ---: | --- |
| `0` | accepted |
| `1` | denied_by_policy |
| `2` | unsupported_profile |
| `3` | invalid_output_id |
| `4` | budget_exceeded |

Denied outputs are valid policy outcomes. Unknown outputs, unsupported profiles,
raw authority, nondeterministic fields, object/map payloads, and private/raw
payloads are failures.

## 6. Evidence Boundary

Evidence may include:

- output ids;
- output names;
- output capabilities;
- arg counts;
- status codes;
- policy decision summaries;
- hashes for any future sensitive scalar policy if separately accepted.

Evidence must not include:

- raw private payloads;
- strings, objects, maps, JSON payloads, pointers, or slices;
- tokens, secrets, credentials, URLs, logs, or private text;
- timestamps or absolute paths;
- host object handles.

## 7. API Gates v0.27

v0.27 API gates should reject:

- `output.event`, `audio.event`, and `effect.event`;
- dynamic `output_id`;
- string/object/map/payload args;
- runtime JSON/object model;
- raw Chrome, DOM, DB, cloud, Kubernetes, Jira, fetch, filesystem, or secret
  authority;
- host object handles;
- automatic host-side action guarantees;
- demo-specific host APIs.

## 8. ABI Decision

AIR ABI remains `0.10`.

Host ABI remains `0.11` only for bounded `output.emit`. v0.27 does not add new
Host ABI imports or change the `output.emit` signature.

Any future expansion requires a separate accepted RFC and promotion evidence.
