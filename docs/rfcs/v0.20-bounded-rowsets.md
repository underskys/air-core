# AIR v0.20 RFC: Bounded Rowset Schema Metadata

Status: active first slice

Target milestone: v0.20

## Purpose

Bounded rowset schemas make host-owned structured facts reviewable without
giving AIR a runtime object model. A bounded rowset schema is package metadata
that describes a fixed, columnar collection of minimized scalar facts. It is
intended for FlowDesk-style task summaries, AirOps-style policy facts,
dashboards, CI pipeline facts, and other bounded scoring inputs.

Bounded rowset schemas are not tablegroups. Rowset schemas are package metadata
and tooling contracts; tablegroups remain future AIR source ergonomics.

## Scope

The v0.20 first slice validates bounded rowset schema files referenced through
the existing `factSchemas` package manifest field:

```json
{
  "factSchemas": ["facts/task_summary.rowset.schema.json"]
}
```

The bounded rowset schema shape is:

```json
{
  "schemaVersion": "0.20",
  "kind": "air.boundedRowsetSchema",
  "name": "task_summary",
  "layout": "columnar",
  "maxRows": 128,
  "columns": [
    {
      "name": "task_id",
      "type": "i32",
      "privacy": "minimized"
    },
    {
      "name": "status_id",
      "type": "i32",
      "enum": "task_status",
      "storageHint": "u8",
      "privacy": "minimized"
    }
  ],
  "privacyPolicy": {
    "defaultClassification": "minimized",
    "forbiddenByDefault": ["raw_text", "raw_url", "token", "secret"]
  }
}
```

## Validation Rules

- `kind` must be `air.boundedRowsetSchema`.
- `schemaVersion` must be `0.20`.
- `name` must be a stable identifier.
- `layout` must be `columnar` in the first slice.
- `maxRows` is required and must be a bounded positive integer.
- `columns` is required and must be non-empty.
- Column names must be stable identifiers.
- Duplicate column names fail.
- Supported column types are `i32` and `bool`.
- String, object, map, JSON, blob, host object, dynamic, and unbounded columns
  fail.
- `rows`, `data`, and `values` fields fail. Bounded rowset schemas describe
  shape only, not runtime rows, runtime data, or values.
- Schema metadata must not encode timestamps or absolute local paths.
- `privacyPolicy` is optional but must be an object when present.
- `defaultClassification` and column `privacy` must use stable documented
  classifications.
- Forbidden privacy markers such as `raw_text`, `raw_url`, `token`, and
  `secret` may appear in `forbiddenByDefault`, but must not be used as allowed
  column classifications.
- `storageHint` may be `u8`, `u16`, `i16`, `i32`, or `bool` as metadata only.
- `range` metadata, when present, must be `[min, max]` integer bounds.

## Report And Evidence

`package-check`, `report package --json`, and verification evidence expose:

- rowset schema path;
- fingerprint/hash;
- schema version and kind;
- rowset name, layout, and `maxRows`;
- column count;
- column names, scalar types, enum labels, ranges, privacy values, and storage
  hints;
- privacy policy summary;
- estimated storage bytes and estimated savings when compact storage hints are
  present;
- rowset diagnostics.

The first slice reuses the `factSchemas` evidence path. It does not create a
parallel evidence channel.

## Diagnostics

Stable rowset diagnostics include:

- `air.rowset.schema_invalid`
- `air.rowset.missing_schema`
- `air.rowset.duplicate_column`
- `air.rowset.unbounded_rows`
- `air.rowset.non_scalar_column`
- `air.rowset.absolute_path`
- `air.rowset.timestamp_field`
- `air.rowset.privacy_invalid`
- `air.rowset.storage_hint_invalid`

Package-check must preserve these codes and must not collapse rowset failures
into generic package-check diagnostics.

## ABI Impact

No AIR ABI change is required. Bounded rowset schemas are package metadata and
tooling/report contracts, not executable runtime representation.

No Host ABI change is required. Bounded rowset schemas do not add host imports,
host authority, runtime output streams, or browser/platform APIs.

## Non-goals

- no tablegroup syntax;
- no generated rowset handles;
- no command/result buffers;
- no `output.emit`, `output.event`, `audio.event`, or `effect.event`;
- no runtime JSON object model;
- no arbitrary JSON values inside AIR;
- no dynamic maps;
- no GC;
- no reflection;
- no host object handles;
- no promises, callbacks, or async/await in AIR;
- no runtime imports;
- no raw Chrome/browser authority.

## Acceptance Tests

- valid bounded rowset schema passes package-check;
- missing `maxRows` fails;
- dynamic or unbounded rows fail;
- duplicate column names fail;
- string/object/map/JSON column types fail;
- invalid privacy policy fails;
- forbidden privacy markers fail when used as allowed column classifications;
- invalid storage hints fail;
- compact storage hints are metadata only and do not affect ABI;
- package report exposes rowset metadata;
- verification evidence includes rowset metadata and fingerprint;
- output is deterministic;
- no absolute paths or timestamp-like fields appear in rowset output;
- AIR ABI remains `0.10`;
- Host ABI remains `0.10`.
