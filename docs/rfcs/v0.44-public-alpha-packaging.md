# RFC: v0.44 Public Alpha Packaging

Status: planning

Target milestone: v0.44

## Summary

v0.44 defines the packaging and release-smoke process for the first public alpha
package. It does not publish the package and does not change AIR semantics.

The package under smoke is `@underskys/air-core@0.44.2`. The planned git tag is
`v0.44.2`.

## Non-Negotiables

- Codex must not receive or use an npm token.
- Codex must not run `npm publish`.
- No secrets, private paths, prompt logs, raw review bundles, large demos,
  consumer evidence, hosts, kits, or build outputs may enter the npm package.
- No AIR ABI change.
- No Host ABI change.
- No language feature work.
- No playground, MCP demo, VS Code extension, or demo migration work.

## Package Surface Model

The package uses the `package.json` `files` whitelist as the primary inclusion
mechanism. The public package surface checker must verify the dry-run tarball
and fail if forbidden surfaces appear.

Expected included surface:

- `bin/airc.js`;
- `data/host_profiles/`;
- `src/`;
- `stdlib/`;
- `spec/`;
- launch-safe `examples/public/`;
- selected public conformance fixtures;
- public docs required for install, versioning, security, threat model,
  conformance, and release context;
- `README.md`, `LICENSE`, `NOTICE`, `AUTHORS`, `VERSIONING.md`,
  `CHANGELOG.md`, `SECURITY.md`, `THREAT_MODEL.md`, and `SHOWCASE.md`.

Expected excluded surface:

- `snapshots/`;
- raw review bundles and `REVIEW_RESULTS`;
- prompts and raw chat logs;
- `consumer_evidence/`;
- `requests/` intake files;
- `evals/`;
- `demo/` or `demos/`;
- `hosts/`;
- `kits/`;
- build outputs, generated archives, generated Wasm, `node_modules`, and large
  media.

## Required Smoke Commands

The release checklist should record the exact commands and outputs, without
timestamps as correctness inputs:

```sh
npm run check:public-package-surface
npm pack --dry-run --json
npm pack
node ./bin/airc.js version --json
node ./bin/airc.js check examples/public/safe_policy/module.air
node ./bin/airc.js package-check examples/public/evidence_report --source-only --json
node ./bin/airc.js evidence report examples/public/evidence_report --format markdown -o build/public-smoke/evidence_report.md
```

If a public-clean `run-proof` fixture is available in the package surface, run:

```sh
node ./bin/airc.js run-proof <package-dir> --fixture <fixture.json> --policy <policy.json> --json
```

If `run-proof` requires a consumer proof fixture excluded from the npm package,
the checklist must mark the npm-package `run-proof` smoke as not applicable and
record the repository-only proof separately.

## Local Install Smoke

The real tarball smoke should test installability without publishing:

```sh
npm pack
npm install -g ./underskys-air-core-0.44.2.tgz
airc version --json
npm uninstall -g air-core
rm -f underskys-air-core-0.44.2.tgz
```

If global install is unsafe in the environment, the checklist must state the
limitation and use a local tarball extraction or package-manager sandbox
instead.

## Tag Plan

Planned tag: `v0.44.2`

Before tagging:

- all v0.43/v0.44 release checks pass;
- package surface dry run passes;
- real tarball smoke passes;
- `README.md`, `VERSIONING.md`, `CHANGELOG.md`, and release notes agree on
  `0.44.2`;
- `CONFORMANCE.md` does not claim independent `air-tests 74/74` unless the
  public repo reproduces it;
- `REVIEW_RESULTS/RED_FLAGS.md` has no active red flags.

## Publish Plan

Publish is manual only. Codex may prepare commands and checklists but must not
run them.

Manual publish checklist:

- confirm npm account, 2FA, package name, and access;
- confirm no npm token is stored in repo, prompt logs, review bundles, shell
  history snippets, or CI output;
- run final tarball smoke from a clean checkout;
- run `npm publish --dry-run` manually if desired;
- publish manually from a trusted local shell;
- immediately verify package metadata and install behavior after publish.

## Post-Publish Verification

After manual publish, verify:

```sh
npm view @underskys/air-core@0.44.2 version
npm view @underskys/air-core@0.44.2 license
npm view @underskys/air-core@0.44.2 bin
npm install -g @underskys/air-core@alpha
airc version --json
airc check <launch-safe-example>
npm uninstall -g air-core
```

The post-publish check should also inspect the published package tarball for
the same forbidden surfaces enforced by `check:public-package-surface`.

## ABI Decision

AIR ABI remains `0.10`.

Host ABI remains unchanged. Host ABI `0.11` remains limited to bounded
`output.emit`, with Host ABI `0.10` still supported for packages that do not use
`output.emit`.

If packaging smoke discovers a need for new runtime contracts, host imports, or
language semantics, v0.44 must stop and create a separate RFC. Packaging cannot
silently create ABI scope.
