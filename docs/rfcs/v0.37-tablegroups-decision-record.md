# RFC v0.37: Readonly Tablegroups Decision Record

Status: proposed / PRO decision record

Target milestone: v0.37

## Decision Summary

Decision: A. AIR source syntax first.

A small AIR source syntax is accepted as the preferred first-slice direction,
provided implementation stays narrow and tablegroups lower to existing static
table machinery.

This decision does not implement tablegroups. Parser, verifier, lowering, AIR
ABI, and Host ABI remain unchanged in v0.37 unless a later implementation task
explicitly accepts those changes.

## 1. First Slice Form

Chosen form:

```text
A. AIR source syntax first
```

Rationale:

- tablegroups are primarily an AI-authoring and reviewPolicy anti-slop feature;
- source syntax gives AI authors one canonical way to express grouped readonly
  scalar table data instead of parallel tables or select chains;
- the syntax can remain small, static, scalar-only, and readonly;
- lowering can reuse existing static table/data machinery;
- report/evidence can preserve clear tablegroup metadata without creating a new
  runtime object model.

Rejected for first slice:

- package metadata/generated static tables only as the primary authoring path;
- dual source+metadata implementation in the first slice.

Package metadata and generated artifacts may still appear later as derived
reporting or tooling outputs, but they must not become semantic source of truth.

## 2. Syntax

Proposed first-slice declaration:

```air
tablegroup sections len 3 {
  x:i32 = [0, 120, 240]
  y:i32 = [80, 96, 112]
  w:i32 = [64, 64, 64]
  h:i32 = [16, 16, 16]
}
```

Proposed first-slice access:

```air
%y:i32 = tablegroup.get.i32 @sections.y, %idx
```

Syntax rules:

- `tablegroup` declares package-local readonly static data;
- `sections` is the group name;
- `len 3` is a fixed numeric row count;
- each field has a stable scalar name and type;
- each field initializer is a fixed literal array;
- every field length must equal the declared `len`;
- `@sections.y` names a specific group field;
- `tablegroup.get.i32` reads one scalar value by index.

If exact parser conventions require minor spelling changes, implementation must
preserve the same semantic shape: named group, fixed length, scalar fields,
literal arrays, and field-qualified indexed read.

## 3. Semantics

Readonly tablegroups are:

- readonly;
- static length only;
- scalar fields only;
- package-local authored data;
- verifier-visible;
- report/evidence-visible as metadata.

Verifier/package-check obligations:

- equal-length fields are enforced;
- fixed numeric length is required;
- unsupported field types are rejected;
- static out-of-bounds access is a verifier error;
- dynamic index behavior must be deterministic through a bounds check or the
  existing `table.get` behavior;
- mutation is rejected;
- tablegroup slices, pointers, references, or handles cannot escape;
- runtime objects are rejected;
- runtime JSON is rejected.

Tablegroups are not:

- records with object identity;
- methods;
- mutable pools;
- dynamic arrays;
- maps;
- host object handles;
- host-visible layout contracts;
- runtime JSON payloads.

## 4. Lowering

Lowering direction:

- lower each field to existing static table/data machinery;
- lower `tablegroup.get.<type> @group.field, idx` to the equivalent checked
  static table read;
- preserve deterministic static and dynamic bounds behavior;
- do not introduce host imports;
- do not export tablegroup storage;
- do not expose a host-visible layout contract;
- do not introduce object representation.

Implementation must stop if existing static table machinery cannot safely
support tablegroup lowering without new runtime contracts.

## 5. Report and Evidence

Package report and verification evidence should expose:

- tablegroup name;
- field names;
- field types;
- length;
- byte size;
- generated or lowered table names;
- diagnostics;
- generated artifact freshness if generated tablegroup handles are added later.

Raw private values are not exposed by default. Authored static values may be
visible in source review because they are package-authored data, but reports
should prefer metadata summaries unless raw values are already part of an
explicit source or fixture review surface.

Package diff should expose:

- added/removed tablegroups;
- changed length;
- added/removed fields;
- changed field types;
- changed lowered table identity when available;
- diagnostics and freshness changes when available.

Replay/conformance summaries should expose tablegroup metadata and mismatch
kinds, not raw host-private payloads.

## 6. Diagnostics

Planned stable diagnostics:

| Code | Meaning |
| --- | --- |
| `air.tablegroup.invalid` | Declaration shape is invalid. |
| `air.tablegroup.length_mismatch` | Field literal length does not match group length or related fields diverge. |
| `air.tablegroup.field_type_invalid` | Field type is not accepted for first slice. |
| `air.tablegroup.index_out_of_bounds` | Statically visible index is outside tablegroup bounds. |
| `air.tablegroup.dynamic_index_unchecked` | Dynamic index cannot be proven or lowered to deterministic checked behavior. |
| `air.tablegroup.object_model_rejected` | Tablegroup use attempts object/JSON/map semantics. |
| `air.tablegroup.mutable_rejected` | Tablegroup mutation or mutable-pool behavior was attempted. |

Diagnostics must be suitable for LSP and AI repair hints.

## 7. Kill Criteria

Stop implementation if:

- tablegroups need runtime JSON or object model;
- tablegroups gain methods;
- tablegroups become mutable;
- dynamic rows are required;
- host object handles are needed;
- slices, pointers, references, or table handles escape;
- lowering cannot reuse static table machinery safely;
- a host-visible layout contract is required;
- demo-specific field concepts enter Core;
- AIR ABI or Host ABI changes are required without explicit ABI review.

## 8. ABI Decision

AIR ABI remains `0.10` unless implementation changes the executable runtime
contract, calling convention, package ABI contract, exports, or imports.

Host ABI is unchanged. Readonly tablegroups are package-local static data and do
not require host imports or host authority.

Host ABI latest remains `0.11`, limited to bounded `output.emit`; Host ABI
`0.10` remains the default/baseline for packages that do not use `output.emit`.
