# AirOps-style Capability Boundary

Status: canonical-proof

## Allowed

- Bounded facts.
- Command buffer output intent.
- Deterministic replay.

## Denied

- Real incident system access.
- Secrets.
- Raw host authority.
- Automatic remediation.

## Routing

- Core: canonical example evidence.
- stdlib: none.
- kit: possible future incident-policy helper, not active.
- host adapter: real incident integrations.
- demo-local: none.
- rejected: direct host remediation from AIR.
