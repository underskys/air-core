# Template Capability Boundary

Status: proposed

## Allowed

- Bounded deterministic AIR logic.
- Declared package capabilities/effects.
- Evidence/report/replay metadata.

## Denied

- Raw host authority.
- Secrets and private data.
- Runtime JSON/object models.
- Demo-specific Core APIs.
