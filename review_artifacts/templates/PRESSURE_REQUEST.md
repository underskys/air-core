# PRESSURE_REQUEST

## Required Fields

- title:
- sourceRepo:
- sourceBranch:
- sourceCommit:
- sourcePath:
- bundleKind:
- owner:
- targetLayer:
- routingDecision:
- airAbiImpact:
- hostAbiImpact:

## Problem

Describe the pressure without defining Core semantics.

## Requested Capability

List the requested capability.

## Rationale

Explain why this is or is not generic.

## Alternatives

Existing AIR feature, kit, project-local, host-owned, or no-action alternative.

## Example

```yaml
title: Math helper pressure
sourceRepo: airlang
bundleKind: internal-dev
targetLayer: stdlib
routingDecision: accepted/planned
airAbiImpact: none
hostAbiImpact: none
```
