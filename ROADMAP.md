# AIR Roadmap

The [v0.54.0 release notes](docs/RELEASE_NOTES_0_54_0.md) describe the
documentation-only scope. The [public pure execution contract](docs/v0.54/n54-01/CONTRACT.md)
describes the boundary and does not implement a new runtime.

Read the [open decisions](docs/v0.54/n54-01/OPEN_DECISIONS.md) for the
remaining design choices and the [v0.53.0 release notes](docs/RELEASE_NOTES_0_53_0.md)
for the runtime baseline.

Native AOT and deferred runtime gates require separate review and admission.
