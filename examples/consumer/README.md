# Consumer Examples

Consumer examples and downstream pressure are intentionally separate from the
public Core/npm package surface.

Consumer proof packages and summaries remain useful evidence, but they do not
define AIR Core semantics, AIR ABI, Host ABI, package semantics, or language
features.

Current consumer evidence sources include:

- `examples/lan_observer_readonly_package/`
- `examples/airops_incident_package/`
- `benchmarks/flowdesk_policy_basic/`
- `consumer_evidence/`

These paths are repository evidence/intake surfaces. They are excluded from the
public npm package by the package surface policy.
